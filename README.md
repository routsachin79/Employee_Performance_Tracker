# Employee_Performance_Tracker
Employee Performance Overview
I’m excited to share my Employee Performance Overview, an HR Analytics project developed using Microsoft Power BI, panda to analyze employee attendance, achievement, and performance data.

🎯 Project Objectives

Monitor employee performance and attendance.
Analyze achievement trends across months and departments.
Compare employee achievement by manager.
Understand the distribution of employee performance categories.
Support data-driven HR and management decisions.

📈 Key Performance Indicators (KPIs)
Total Employees: 1K
Average Achievement: 114.29%
Average Attendance: 84.82%
Average Performance Rating: 3.00

📊 Dashboard Features
Department-wise attendance analysis.
Manager-wise achievement comparison.
Monthly achievement trend analysis.
Performance category distribution.
Interactive slicers for Department, Manager, Performance Category, and Month.

💡 Key Insights

Average attendance is approximately 84.82%, highlighting an opportunity to monitor attendance patterns.
Monthly achievement trends help identify fluctuations in employee performance.
Manager-wise analysis enables comparison of achievement levels across teams.
Performance category analysis highlights employees across different performance levels and helps identify areas for improvement.
